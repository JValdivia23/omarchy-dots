# Dell XPS 13 (`xps`) Gotchas & Hardware Progress Directory

This directory holds modular gotcha documentation and hardware troubleshooting progress for the **Dell XPS 13 (`XPS 13 DX13260`)** profile.

All files in `profiles/xps/gotchas/` are automatically symlinked into `~/.agents/skills/system-personalization/references/gotchas/` when `./install.sh` runs on this machine.

When discovering a new hardware quirk, kernel/driver fix, or display/input adjustment on the XPS, document it here using `agents/.agents/skills/system-personalization/templates/gotcha-entry.md`.
